# AI Object Detection using YOLO

## Description
This project performs real-time AI object detection using YOLOv8 and OpenCV.

The system detects multiple objects such as phones, bottles, persons, and laptops through webcam input.

## Technologies Used
- Python
- OpenCV
- YOLOv8
- Ultralytics

## Features
- Real-time object detection
- Bounding boxes
- Multiple object recognition
- AI pretrained model

## Run

pip install ultralytics opencv-python

python yolo_object_detection.py
